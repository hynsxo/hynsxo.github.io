소개

KIST에서는 드럼 로봇의 동작이 어긋나는 원인을 통신 데이터에서 찾아, 잘 동작하던 기존 통신은 그대로 두고 필요한 순간에만 위치를 다시 읽도록 고쳤습니다. IBK기업은행에서는 송금 오류를 처리하는 행원들을 직접 찾아가 들은 내용으로 검증 방안을 만들었고, 실제 개발 안건으로 채택되었습니다.

8년째 매일 플래너와 일기를 쓰며, 우선순위를 매겨 중요도에 따라 문제를 해결합니다.

프로젝트 및 경험

로보틱스 · 임베디드2024.12 – 2025.02

악보를 읽고 양팔로 드럼을 치는 10자유도 로봇을 개발했습니다. 타격 순간마다 팔 동작이 미세하게 어긋나는 문제가 있었습니다.

  • CANopen 통신 데이터를 추적해, 제어 모드 전환 순간 최신 위치 대신 이전 주기(5ms)의 위치값을 쓰는 원인 확인
  • 통신 주기를 1ms로 줄이는 안은 IK 기반 동작 계산 전체를 고쳐야 해 제외
  • 기존 PDO 주기 통신은 유지하고, 전환 순간에만 SDO로 최신 위치를 읽는 하이브리드 구조 설계·구현
  • 시뮬레이션과 실제의 차이로 부품이 파손된 뒤, ‘시뮬레이션 → 50% 속도 실기동 → 오차 기록·궤적 보정’ 3단계 검증 절차 도입
  • 그 외 다익스트라·보간법 궤적 생성, PID 튜닝, GDB 디버깅, 협업 규칙·코드 흐름 문서화

기존 제어 구조를 거의 바꾸지 않고 타격 동작을 매끄럽게 개선했습니다. 3단계 검증 절차는 도입 후 충돌 0건으로 팀 표준이 되었습니다.

해외송금에서 수취 계좌를 잘못 적어 송금이 취소되는 일이 반복되어, 고객과 은행 모두 취소 수수료와 사후 처리 부담을 지고 있었습니다.

  • 이 오류를 처리해 온 행원들을 직접 찾아가 오류가 잦은 상황과 불편 수집
  • 계정계(핵심 거래 시스템) 데이터 흐름을 도식화하고 오류 사례를 유형별로 분류해, 특정 국가·은행 코드 조합의 반복 패턴 확인
  • 타행 사례 비교 후 3중 검증 구조 기획: 송금 이력 대조 · SWIFT API 조회 · 계좌번호 형식 검증
  • 기존 시스템과의 연계 방안까지 검토해 제안서 작성

‘취소 수수료를 막을 수 있다’는 평가와 함께 실제 개발 안건으로 채택되어 33기 우수 인턴으로 선정되었습니다.

  • 광역교통 수요 데이터로 분석 지점 선정: 강남·홍대입구·서울역
  • QGIS로 주거·상업지구 밀도를 지도화하고, 소음·진동관리법 기준 비율로 지역별 가중치 산출
  • 팀원은 김포공항 실측 소음과 UAM 인증기준으로 거리별 소음 예측 회귀모델 구축
  • 두 결과가 맞물리지 않아 모델을 다이어그램으로 나란히 비교 → 제 가중치에 빠져 있던 고도 축을 찾아 고도별로 세분화
  • 네 방향 항로마다 좌우 17칸 격자에 예측 소음과 가중치를 넣어 비교

같은 지점도 항로 방향에 따라 결과가 달라짐을 수치로 보였고(서울역 평균 이상 소음 영역: 동서 39.7%, 남서–북동 31.8%), 한국공항공사 사장상을 받았습니다.

외국인 학생이 한국 생활과 학사 행정에서 겪는 어려움을 파악하고, 정확한 정보를 쉬운 영어로 안내하는 역할을 맡았습니다.

  • 비자 연장과 주거 등 한국 생활에 필요한 행정 절차를 영어로 안내
  • 확실하지 않은 내용은 담당 부서에 확인한 뒤 전달하고, 약속한 기한을 지켜 신뢰를 형성
  • 다양한 국적의 학생·교직원과 함께 일하며 상대와 상황에 맞게 소통하는 역량을 강화

담당자가 자리에 없을 때에도 학생들이 저를 찾아올 만큼 신뢰를 쌓았고, 담당 교직원에게서 ‘어디서든 환영받을 사람’이라는 평가를 받았습니다. 상대방의 상황부터 확인하는 이 태도는 이후 IBK기업은행 인턴 때의 금융 서비스 개선 과제로도 이어졌습니다.

  • 성향 점수로 비슷한 날을 찾던 구조를, 일기 문장 자체를 검색하는 RAG 구조로 재설계
  • 자정마다 당일 일기와 비슷한 과거 기록을 FAISS(L2 거리)로 찾아 GPT 프롬프트에 예측 근거로 포함
  • GPU 없는 EC2에서도 한국어 검색이 되는 다국어 경량 임베딩 MiniLM(384차원) 선정
  • 앱 단독 처리는 품질·메모리 한계로 제외하고, 연산과 GPT 호출은 FastAPI 서버로 분리
  • 민감정보 정규식 마스킹, 미션 수행 시 성향 점수가 갱신되는 자기 보정 루프 구현

30명이 한 달간 실제로 사용했고, 피드백을 반영해 다음 날 날씨를 입력값에 추가했습니다.

객체 탐지 모델의 출력값을 온도 제어 기능으로 연결하면서, 모델 성능뿐 아니라 예측 결과를 실제 서비스에서 어떻게 활용할지도 함께 고민했습니다.
